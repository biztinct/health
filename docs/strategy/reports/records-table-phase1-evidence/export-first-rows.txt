==============================================================================
WHY THIS IS THE 'NAMES, NOT IDS' PROOF
==============================================================================
'Catchment Area' is bi.field 574, a many2one onto health.catchment.province
(ids 1 and 2 in the database). The pre-existing GET export wrote
str(value) — i.e. "1" / "2". Both files above carry "TPHCM" / "Hà Nội",
because both routes now build the workbook from the POST-label envelope
(engine.run -> _attach_relation_labels) and _write_cell looks the value up
in column['value_labels'] before anything else.

'Scheduled Date' is a real Excel date (num_format yyyy-mm-dd), not a string,
and 'Total Price' is a real number (#,##0.00) — so sorting and SUM() work in
Excel without touching the file.
