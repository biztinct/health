The actual to-do list

Five providers, each unlocking one or more channels

Everything above collapses to five external relationships. None of them are Health19 development work — they are accounts, forms and reviews on someone else's website.

MetaBLOCKED
Unlocks WhatsApp + Messenger
  1. Create a Business-type app and complete Business Verification.
  2. Pass App Review for five permissions: whatsapp_business_management, whatsapp_business_messaging, pages_show_list, pages_messaging, pages_manage_metadata.
  3. Create an Embedded Signup configuration for WhatsApp and a Login for Business configuration for Messenger.
  4. Paste the redirect URI and both webhook URLs (generated on our side) into the app, with the verify token.
Business verification is the long pole — often 1–3 weeks, and can bounce back for more documents.
ZaloBLOCKED
Unlocks Zalo chat + ZNS notifications
  1. Create an app on Zalo Developers and link it to the Official Account.
  2. Add our redirect URI to the app's OAuth settings.
  3. Set the single webhook URL Zalo allows per app — every tenant's OA shares it, routed by account id on our side.
ZNS needs one more thing on top: a funded ZCA account, then each message template individually reviewed by Zalo (2–3 days, per template).
GoogleBLOCKED
Unlocks Email (Gmail)
  1. Create an OAuth 2.0 Client ID in Google Cloud Console and enable the Gmail API.
  2. Add our redirect URI to Authorised redirect URIs.
  3. Publish the consent screen — or list every clinic mailbox as a test user. An unpublished screen silently expires connections after 7 days.
  4. For full read/send access: a restricted-scope + CASA security assessment (4–12 weeks, a lab fee). A send-only version can ship sooner without it.
MicrosoftBLOCKED
Unlocks Email (Microsoft 365)
  1. Register an app in Microsoft Entra ID; add the Mail.Send, Mail.ReadWrite, IMAP.AccessAsUser.All and offline_access permissions.
  2. Add our redirect URI as a Web redirect URI.
  3. Create a client secret — Entra secrets expire, so the expiry date needs tracking.
Only one of Google or Microsoft is required to light the Email card — pick whichever the clinic's own mailboxes already run on.
VoIP24hBLOCKED
Unlocks Calls — receiving only
  1. Fetch VoIP24h's real API documentation from docs-sdk.voip24h.vn — geo-blocked to Vietnam IPs only.
  2. Reconcile it against the endpoints already built (they were written from public traces, never confirmed against the real spec).
  3. Get VoIP24h support to issue account credentials and confirm their webhook signature scheme.
Outbound calling was never in scope here — this channel only ever listens for call events VoIP24h sends us.

Where a provider app actually gets entered

The operator console

Once any one of the five provider relationships above is ready — an app id, a secret, a couple of configuration ids — there is exactly one place to enter it: Platform Applications, one row per provider (Meta / Zalo / Google / Microsoft). Filling that row is the whole activation: no code change, no redeploy. Its own "Go Live" tab shows the redirect URI and webhook URLs to paste back into the provider's console, and a self-test button that calls the provider directly and reports back in plain words.

One rough edge

This screen is reachable only by typing its address directly — it has no link in the sidebar and doesn't appear in the app switcher. Fine for now with one operator; worth a proper menu entry before a second person needs to find it.

Two small things, neither blocking

Known software gaps

  • Reply Templates can only be tagged for Zalo, Calls, Email, ZNS or "Any channel" — WhatsApp, Messenger, Telegram and Web Chat aren't offered yet, even though all four channels are otherwise live in the framework. A five-minute fix once someone needs a WhatsApp-specific canned reply.
  • "Add another account" — the button that lets one clinic run, say, a Hanoi Zalo account and a separate HCMC one — only appears once a channel has both a working first connection and its provider app is registered. Until the steps above are done, it stays hidden. It is not missing; it has nothing to attach a second account to yet.
