# Design Mode Command

## Command: `/design-mode`

### Description
Activates design and prototyping mode for frontend development. When this command is used, Claude will focus on UI/UX design, frontend improvements, and visual enhancements rather than backend logic or database changes.

### Usage
```
/design-mode [component-name]
```
