Top bar, menu, listsSegoe UI → Arial
  • The two fonts the theme names are never shipped, so the browser quietly swaps them. On a Mac the client's name is Arial beside system-font fields; on Windows everything is Segoe UI.
  • Numbers do not line up (prices, dates, counts use proportional digits almost everywhere).

Recommendation

  • One real typeface, shipped with the app (no Google call, works offline, every tenant the same). Inter is already what the theme asked for; Be Vietnam Pro is the warmer alternative built for Vietnamese. Pick on this page.
  • One weight ladder: 400 text, 500 values, 600 labels and buttons, 700 the record name. Nothing at 800.
  • Lined-up numbers everywhere a figure appears (At a glance, invoices, lists, chips).
  • Room for Vietnamese marks: no line tighter than 1.25 where a name or chip can carry ấ, ỗ, ữ.
  • Colours, spacing, cards, icons, layout: unchanged

Effect on Form Studio

  • None A typeface is a theme setting. Form Studio adds fields and places them on cards; the cards already take their type from the theme, so a custom field looks like a standard one automatically (see the Clinic details card below).
  • Both land through the theme module only. They can ship in either order and never touch the same file.
  • Size: about one day, one module, one deploy to every database. Font files ≈ 100 KB.
  • Does not touch the nurse app, the family pages or printed invoices, which have their own fonts. follow-up
