# PruLearn360 - Executive Summary

**Prudential Learning Excellence & Analytics Platform**
**1-Page Overview for Decision Makers**

---

## What is PruLearn360?

A comprehensive **Learning Management + Sales Enablement + AI Assistant** platform that unifies Prudential's existing systems (Docebo + PD Platform) with intelligent automation, real-time analytics, and mobile-first design.

**Built on 100% free, open-source technology** - zero licensing costs, ever.

---

## The Problem

**Current State**:
- ❌ **Fragmented systems**: Docebo (learning), PD Platform (performance), manual processes
- ❌ **No real-time insights**: Weekly/monthly manual reports, delayed intervention
- ❌ **Manual workflows**: Training requests, coaching schedules, capability tracking
- ❌ **Limited support**: No on-demand sales knowledge for agents
- ❌ **Desktop-only**: Field agents lack mobile access

**Business Impact**:
- Delayed capability development
- Inefficient training resource allocation
- Lost productivity (manual coordination)
- Suboptimal agent performance

---

## The Solution: PruLearn360

### Core Capabilities

**1. Automated Learning Roadmap Management**
- Skills assessment (auto-scored)
- Performance × Skills capability segmentation
- Auto-assign personalized learning paths
- Auto-enroll in Docebo courses
- Real-time progress tracking

**2. Real-Time Capability Analytics**
- Executive dashboard (system-wide KPIs)
- Bank leader dashboard (team heatmap)
- Agent dashboard (personal progress)
- Trainer dashboard (workshop metrics)
- Embedded Metabase visualizations

**3. AI Sales Chatbot**
- Local Llama 3 LLM (no API costs, data private)
- Sales knowledge Q&A (Vietnamese + English)
- Source citations for transparency
- Available 24/7 on desktop + mobile

**4. Coaching & Action Plan Management**
- Calendar-based coaching scheduler
- Behavior assessment (Banca+ steps)
- Action plan tracking with notifications
- Field site visit logging
- Manager effectiveness dashboard

**5. Mobile Progressive Web App (PWA)**
- Install on iOS/Android (no app store)
- Offline-capable forms
- Push notifications
- Camera + GPS integration
- 100% responsive design

**6. Training Request Ticketing**
- Structured request workflow
- RTM approval routing
- Auto-create training sessions
- Status tracking & analytics
