# PWA Video Tutorial Specifications

This document outlines the video tutorials needed for the PWA rollout training program.

## Overview

Two platform-specific video tutorials are required:
1. **iOS Installation & Usage** (Vietnamese voiceover)
2. **Android Installation & Usage** (Vietnamese voiceover)

**Budget**: $300 total (in-house production)
**Timeline**: Week 1 of rollout preparation
**Language**: Vietnamese primary, English subtitles optional

## Production Guidelines

### Screen Recording Setup

#### iOS Recording
**Option 1: iPhone Screen Recording (Recommended)**
- Use built-in screen recording: Control Center → Screen Recording
- Enable microphone for narration later
- 1080p minimum resolution

**Option 2: QuickTime + iPhone (macOS)**
- Connect iPhone to Mac via cable
- QuickTime Player → New Movie Recording → Select iPhone
- Record screen while demonstrating

**Option 3: Reflector or AirServer (Wireless)**
- Mirror iPhone screen to computer wirelessly
- Record with OBS Studio or similar

#### Android Recording
**Option 1: Android Built-in (Android 11+)**
- Settings → System → Advanced → Developer Options → Enable "Screen Recording"
- Or use built-in screen recorder app

**Option 2: ADB + scrcpy (Advanced)**
- Mirror Android screen to computer
- Record with OBS Studio

**Option 3: Mobizen or AZ Screen Recorder (Apps)**
- Install screen recording app from Play Store
- Record directly on device

### Audio Recording

#### Vietnamese Voiceover
**Narrator requirements**:
- Native Vietnamese speaker
- Clear pronunciation
- Professional or semi-professional recording setup

**Equipment**:
- USB microphone (minimum Blue Yeti or similar)
- Quiet room with minimal echo
- Audio interface optional

**Software**:
- Audacity (free) for recording
- Remove background noise
- Normalize audio levels
- Export as MP3 or WAV

#### Recording Script
- Print Vietnamese narration scripts
- Mark breathing points
- Practice before recording
- Record in segments (easier to edit)

### Video Editing

**Software Options**:
- **iMovie** (macOS, free) - Good for basic editing
- **DaVinci Resolve** (free) - Professional features
- **Shotcut** (free, cross-platform) - Simple and effective
- **Adobe Premiere Pro** (paid) - Industry standard

**Editing Workflow**:
1. Import screen recordings
2. Trim clips to match script timing
3. Add on-screen annotations:
   - Arrows pointing to buttons
   - Circles highlighting areas
   - Text overlays for steps
4. Sync Vietnamese voiceover audio
5. Add subtle background music (optional, Vietnamese-friendly)
6. Add intro/outro graphics
7. Color correction if needed
8. Export to MP4

### Annotations & Graphics

**On-screen Elements**:
- **Step numbers**: Large, clear Vietnamese text (e.g., "Bước 1", "Bước 2")
- **Arrows**: Bright color (#FF5722 orange or #4CAF50 green)
- **Circles**: Semi-transparent highlight overlays
- **Text boxes**: Vietnamese instructions with readable font (Roboto, Open Sans)

**Branding**:
- Use VAFHS/Viet Uc logo in intro/outro
- Brand colors: #875A7B (purple theme from app)
- Consistent lower-third graphics for narrator info

### Background Music (Optional)

**Requirements**:
- Royalty-free music
- Subtle, non-intrusive (avoid Vietnamese pop music that may distract)
- Volume: -20dB to -30dB (voiceover should be primary)

**Sources**:
- YouTube Audio Library (free)
- Epidemic Sound (paid subscription)
- Artlist (paid subscription)

### Export Settings

**High Quality (for website embedding)**:
- Format: MP4
- Codec: H.264
- Resolution: 1920×1080 (1080p)
- Bitrate: 8-10 Mbps
- Audio: AAC, 192 kbps stereo
- Target file size: <100MB

**Medium Quality (for Zalo sharing)**:
- Format: MP4
- Codec: H.264
- Resolution: 1280×720 (720p)
- Bitrate: 4-5 Mbps
- Audio: AAC, 128 kbps stereo
- Target file size: <50MB

**Low Quality (for WhatsApp, if needed)**:
- Format: MP4
- Resolution: 854×480 (480p)
- Bitrate: 2 Mbps
- Target file size: <20MB

## Hosting & Distribution

### Hosting Options

**Option 1: YouTube (Unlisted)**
- Upload to VAFHS YouTube channel
- Set to "Unlisted" (not public, but accessible via link)
- Benefit: Free hosting, reliable streaming
- Embed in installation page: `<iframe>` embed code

**Option 2: Vimeo (Private)**
- Upload to Vimeo account
- Set to "Private" with password or domain restriction
- Benefit: Professional appearance, no ads
- Cost: ~$7/month for Basic plan

**Option 3: Self-hosted**
- Upload to Odoo server: `/health_pwa/static/videos/`
- Serve via Odoo controller
- Benefit: Complete control
- Drawback: Server bandwidth usage

**Recommended**: YouTube Unlisted + self-hosted backup

## Accessibility Considerations

### Closed Captions (Vietnamese)
- Include Vietnamese CC for hearing-impaired users
- Use YouTube's auto-caption as baseline, edit for accuracy
- Ensure text on-screen is readable (minimum 16px font size equivalent)

### Visual Clarity
- High contrast for text overlays
- Avoid relying solely on color (use icons/arrows too)
- Test on small screens (mobile viewing)
