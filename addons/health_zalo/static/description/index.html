🚀 Health Zalo Integration

Complete Zalo Official Account integration for Healthcare management in Odoo 18

✨ Key Features

📱 Real-Time Messaging

  • Live chat interface with Zalo users
  • Send and receive text messages, images, and files
  • Message status tracking (sent, delivered, read)
  • Conversation history and search

🔐 OAuth 2.0 Authentication

  • Secure connection to Zalo Official Account
  • Automatic token refresh
  • Multi-company support
  • Connection testing and troubleshooting

🔔 Real-Time Notifications

  • Instant alerts for new Zalo messages
  • Browser notifications with sound
  • Webhook integration for live updates
  • Unread message counters

👥 Contact Integration

  • Link Zalo users to Odoo contacts
  • Patient and contact Zalo integration
  • Quick chat/call actions from contact records
  • Conversation smart buttons

💬 Professional Chat Widget

  • Modern, responsive Owl.js component
  • WhatsApp/Messenger-style interface
  • Typing indicators and read receipts
  • Mobile-optimized design

🛠 Technical Stack

Backend:
  • Zalo Official Account API v2.0
  • Python requests library
  • Odoo 18 ORM and services
  • Webhook controller with async processing
Frontend:
  • Owl.js (Odoo 18 JavaScript framework)
  • SCSS styling
  • Odoo bus.bus for real-time updates
  • Browser Notification API

📋 Requirements

  • Odoo 18.0 Community or Enterprise
  • health_base module
  • Zalo Official Account (register at developers.zalo.me)
  • HTTPS-enabled Odoo server (for webhooks)
  • Python requests library
