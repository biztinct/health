# Healthcare Theme (Odoo 18 CE)

A calm, clinical, AA-accessible palette for the Odoo backend and website.

## Install
1. Copy `hc_theme` to your addons path.
2. Apps → Update Apps List → Install "Healthcare Theme (Backend + Website)".
3. To apply edits later, upgrade the module or run `-u hc_theme -d <db>`.

## Notes
- Primary: #0F6D66
- Secondary: #2E6F89
- Background: #F7FAF9
- Surface: #ECF5F3
- Border: #CFE3E1
- Text: #0E1B1B
